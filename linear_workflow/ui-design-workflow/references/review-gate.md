# UI Review Gate
- Approved UX screen/flow coverage and traceability verified.
- Components, tokens, spacing and responsive rules consistent.
- Loading, empty, errors, permissions, focus and keyboard states specified.
- Accessibility checks documented, not asserted without evidence.
- Delivery mode recorded: Visual Required needs accessible actual visual artifacts for the agreed screen/state scope; missing visuals block completion. Spec Only requires explicit user choice and a recorded visual-delivery exception.
- User approves the scope and artifacts, with date/version and exceptions.
