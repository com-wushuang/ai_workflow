# MVP Planning Review Gates

G0 — Input accepted: Product Brief explicitly approved, project and canonical source known, invocation authorizes interview start.
G1 — MVP outcome and hypotheses recorded; unresolved decisions identified.
G2 — Must-have / Later / Out-of-scope choices reflect recorded user decisions, with rationale and dependencies; existing decisions require no repeated approval.
G3 — Validation signals, constraints, risks and non-goals recorded.
G4 — Complete `MVP-Scope.md` reviewed and explicitly approved.
G5 — Linear change plan separately approved; actual changes verified.

At checkpoints, record confirmed facts, assumptions and open decisions. Pause at G2 only for unresolved material choices, G4 for final artifact approval, and G5 for a batch not already authorized. Internal transitions need no approval. Never interpret G4 as permission to enter PRD or G5 as permission to create development issues.

Review checklist:
- Every major MVP choice traces to the Product Brief or a documented user decision.
- Must-have scope is the smallest coherent usable/testable slice.
- Exclusions are explicit; dependencies and unknowns are visible.
- Validation is measurable or marked TBD; no fabricated numeric targets.
- No premature PRD, wireframes, architecture or code.
- Approval history is clear and no unapproved Linear writes occurred.
