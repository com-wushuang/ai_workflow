# UX Review Gate
- Approved PRD stories trace to flows/screens; no unapproved scope expansion.
- Primary and alternate paths, error/empty/loading/permission states covered.
- Navigation and terminology consistent; usability and accessibility considered.
- Visual deliverable links are genuine, not claimed from text-only files.
- Risks, assumptions and unresolved decisions visible.
- User explicitly approves this stage; record approver, date, version and remaining exceptions.
